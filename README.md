# Oddware

Small tools for everyday problems, built as I go.

## Why?

I keep coming across small problems, repetitive tasks, and things that feel unnecessarily manual.

Instead of just working around them, I want to build something.

**Notice → Build → Use → Learn → Improve**

This repository is where those experiments live.

## What's Inside?

Small utilities, scripts, automations, and experiments built to solve real problems.

| Utility                                  | Description                                           | Tech |
| ---------------------------------------- | ----------------------------------------------------- | ---- |
| [Dynamic Wallpaper](./dynamic-wallpaper) | Automatically changes Windows wallpaper based on time | Go   |

More odd little tools coming as I find problems worth solving.

## Principles

- Solve real problems
- Keep things small
- Prefer simple solutions
- Learn by building
- Ship before over-engineering
- If something becomes genuinely useful, explore it further

## The Goal

Not every project here needs to become a product.

The goal is to **build more, learn more, and discover better ideas along the way.**
